# 🔐 Projeto Login - HTML e CSS

Este projeto é uma **tela de login responsiva**, criada como parte dos meus estudos de **HTML5** e **CSS3**. O layout simula uma interface moderna de autenticação, com campos para e-mail e senha, ícones do Google Fonts e tratamento visual via CSS e media queries.
